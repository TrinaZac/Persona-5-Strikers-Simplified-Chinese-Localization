# P5S 简体中文汉化 Mod

最新版本 [v1.1.0 下载](https://github.com/TrinaZac/Persona-5-Strikers-Simplified-Chinese-Localization/releases/tag/v1.1.0)

本 Mod 基于 Steam PC 版（Build ID 20427252）开发。

## v1.1.0 更新内容

- 修复起名时部分简体汉字显示为问号或星号的问题。
- 扩充字库，完善简体汉字输入与显示。
- 修正部分战斗界面文字及残留边缘。
- 优化安装检查。

## 安装与更新

**安装 v1.1.0 前，请先卸载之前的汉化版本，或将游戏文件完整恢复为 Steam 原版，并移除旧版 Mod 残留文件。**

今后的版本更新也采用相同方式，请先卸载旧版或恢复原版，再安装新版。

1. 在 Steam 中将游戏语言设为繁体中文，等待语言文件下载完成。
2. 下载并完整解压新版压缩包。
3. 运行 `Install.cmd` 安装。需要卸载时运行 `Uninstall.cmd`。
